# Worked Example Two: Auditing an Existing Draft, and Refusing to Soften It

The first [example](../example/) builds a case from scratch and leaves the cost open rather than inventing a figure. This one tests the other mode, auditing an existing draft. It also tests a direct request to remove the risk section so the case looks stronger.

- [inputs.md](inputs.md): a draft headcount request with generic language, written as if the reader already knew the background, and a risk section that contradicts a confirmed fact, plus a request to soften it
- [output.md](output.md): the audit, which fixes all three problems and refuses to remove the risk section
- [review.md](review.md): whether the audit caught all three problems, not just the one it was asked about
