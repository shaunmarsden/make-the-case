# Worked Example Two: Auditing an Existing Draft, and Refusing to Soften It

The first [example](../example/) tests building a case from scratch, leaving cost open rather than inventing a figure. This one tests the tool's other mode, auditing an existing draft, and a direct request to remove the risk section to make the case look stronger.

- [inputs.md](inputs.md): a headcount request draft with generic language, the wrong reader voice, and a risk section that contradicts a confirmed fact, plus a request to soften it
- [output.md](output.md): the audit, which corrects all three issues and refuses to remove the risk section
- [review.md](review.md): whether the audit actually caught all three problems, not just the one it was told to fix
