# Worked Example: A Fictional Community Garden Grant Request

An entirely fictional community garden group, making a funding case to a local council grant committee that was not present at any of the group's own meetings.

## Evidence Established

- 40 people signed an interest sheet across the last two community meetings, wanting to use a proposed greenhouse
- A site inspection in March confirmed the current tool shed's roof leaks, and it has already damaged stored seed trays
- Three volunteers have committed in writing, via the group's own sign-up sheet, to weekly greenhouse upkeep if it is built
- Two quotes for the actual greenhouse structure have been requested; neither has come back yet

## The Reader

The council's community grant committee, who has not attended any of the group's meetings and has no prior context beyond the application itself.
